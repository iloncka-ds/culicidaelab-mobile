# Начало работы с CulicidaeLab

Добро пожаловать в CulicidaeLab — ваше комплексное мобильное приложение для идентификации видов комаров и информации о заболеваниях. Это руководство поможет вам эффективно начать использовать приложение.

## Что такое CulicidaeLab?

CulicidaeLab — это научное мобильное приложение, предназначенное для помощи пользователям в идентификации видов комаров с использованием искусственного интеллекта и изучения заболеваний, переносимых комарами. Приложение сочетает передовое машинное обучение с комплексным образовательным контентом для поддержки как гражданской науки, так и осведомленности о общественном здравоохранении.

### Ключевые функции

- **Идентификация на основе ИИ**: Используйте камеру телефона для мгновенной идентификации видов комаров
- **Галерея видов**: Просматривайте подробную информацию об опасных видах комаров
- **Информация о заболеваниях**: Изучайте заболевания, передаваемые комарами
- **Интерактивная карта**: Просматривайте данные о активности комаров со всего мира
- **Многоязычная поддержка**: Доступно на английском, испанском и русском языках

## Системные требования

### Устройства Android
- **Операционная система**: Android 5.0 (API Level 21) или новее
- **ОЗУ**: Минимум 3 ГБ (рекомендуется 4 ГБ+ для оптимальной производительности)
- **Хранилище**: Не менее 300 МБ свободного места
- **Камера**: Требуется для идентификации комаров
- **Интернет**: Требуется для функций карты и отправки наблюдений

### Устройства iOS
- **Операционная система**: iOS 12.0 или новее
- **ОЗУ**: Минимум 3 ГБ (рекомендуется 4 ГБ+)
- **Хранилище**: Не менее 300 МБ свободного места
- **Камера**: Требуется для идентификации комаров
- **Интернет**: Требуется для функций карты и отправки наблюдений

## Установка

### Из магазинов приложений
1. **Android**: Найдите "CulicidaeLab" в Google Play Store
2. **iOS**: Найдите "CulicidaeLab" в Apple App Store
3. Нажмите "Установить" или "Получить" для загрузки приложения
4. Дождитесь завершения установки

### Первый запуск
При первом открытии CulicidaeLab:
1. Приложение загрузит модель ИИ (это может занять несколько секунд)
2. Вы увидите главный экран с опциями навигации
3. Предоставьте разрешения на камеру и местоположение при запросе
4. Выберите предпочитаемый язык в меню настроек

## Разрешения

CulicidaeLab требует определенных разрешений для правильной работы:

### Обязательные разрешения

**Доступ к камере**
- **Цель**: Делать фотографии комаров для идентификации
- **Когда запрашивается**: При первом использовании функции камеры
- **Влияние при отказе**: Нельзя делать новые фотографии, но можно выбирать из галереи

**Доступ к фотогалерее**
- **Цель**: Выбирать существующие фотографии для идентификации
- **Когда запрашивается**: При первом выборе из галереи
- **Влияние при отказе**: Нельзя выбирать существующие фотографии, но можно использовать камеру

**Службы геолокации**
- **Цель**: Добавлять данные о местоположении к наблюдениям и просматривать соответствующие данные карты
- **Когда запрашивается**: При отправке наблюдений или доступе к функциям карты
- **Влияние при отказе**: Нельзя отправлять наблюдения с данными о местоположении

### Управление разрешениями
Если вы изначально отказали в разрешениях, вы можете включить их позже:

**Android:**
1. Перейдите в Настройки > Приложения > CulicidaeLab > Разрешения
2. Включите разрешения, которые хотите предоставить

**iOS:**
1. Перейдите в Настройки > Конфиденциальность и безопасность > [Тип разрешения]
2. Найдите CulicidaeLab и включите его

### Отказ от ответственности для образовательного использования
CulicidaeLab предназначен для образовательных и исследовательских целей. Хотя система идентификации ИИ очень точна, она не должна заменять профессиональные медицинские советы или официальные рекомендации здравоохранения. Всегда консультируйтесь с медицинскими работниками и органами общественного здравоохранения по медицинским вопросам, связанным с заболеваниями, переносимыми комарами.
