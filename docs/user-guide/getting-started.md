# Getting Started with CulicidaeLab

Welcome to CulicidaeLab, your comprehensive mobile application for mosquito species identification and disease information. This guide will help you get started with using the app effectively.

## What is CulicidaeLab?

CulicidaeLab is a scientific mobile application designed to help users identify mosquito species using artificial intelligence and learn about mosquito-borne diseases. The app combines cutting-edge machine learning with comprehensive educational content to support both citizen science and public health awareness.

### Key Features

- **AI-Powered Identification**: Use your phone's camera to identify mosquito species instantly
- **Species Gallery**: Browse detailed information about dangerous mosquito species
- **Disease Information**: Learn about diseases transmitted by mosquitoes
- **Interactive Map**: View mosquito activity data from around the world
- **Multi-language Support**: Available in English, Spanish, and Russian

## System Requirements

### Android Devices
- **Operating System**: Android 5.0 (API Level 21) or newer
- **RAM**: Minimum 3 GB (4 GB+ recommended for optimal performance)
- **Storage**: At least 300 MB of free space
- **Camera**: Required for mosquito identification
- **Internet**: Required for map features and observation submission

### iOS Devices
- **Operating System**: iOS 12.0 or newer
- **RAM**: Minimum 3 GB (4 GB+ recommended)
- **Storage**: At least 300 MB of free space
- **Camera**: Required for mosquito identification
- **Internet**: Required for map features and observation submission

## Installation

### From App Stores
1. **Android**: Search for "CulicidaeLab" in Google Play Store
2. **iOS**: Search for "CulicidaeLab" in Apple App Store
3. Tap "Install" or "Get" to download the app
4. Wait for installation to complete

### First Launch
When you first open CulicidaeLab:
1. The app will load the AI model (this may take a few seconds)
2. You'll see the home screen with navigation options
3. Grant camera and location permissions when prompted
4. Choose your preferred language from the settings menu

## Permissions

CulicidaeLab requires certain permissions to function properly:

### Required Permissions

**Camera Access**
- **Purpose**: Take photos of mosquitoes for identification
- **When requested**: First time you try to use the camera feature
- **Impact if denied**: Cannot take new photos, but can still select from gallery

**Photo Library Access**
- **Purpose**: Select existing photos for identification
- **When requested**: First time you try to select from gallery
- **Impact if denied**: Cannot select existing photos, but can still use camera

**Location Services**
- **Purpose**: Add location data to observations and view relevant map data
- **When requested**: When submitting observations or accessing map features
- **Impact if denied**: Cannot submit observations with location data

### Managing Permissions
If you initially denied permissions, you can enable them later:

**Android:**
1. Go to Settings > Apps > CulicidaeLab > Permissions
2. Toggle on the permissions you want to grant

**iOS:**
1. Go to Settings > Privacy & Security > [Permission Type]
2. Find CulicidaeLab and toggle it on
